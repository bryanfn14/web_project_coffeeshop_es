# Triple Espresso

Nombre del proyecto: Landing Page Triple Espresso.

Descripción del proyecto: Landing page con encabezado, formulario y pie de página para realizar reservas de mesas en una cafeteria, usando HTML y CSS, se aplicaron las metodologias BEM para la estructura de las clases.

Se planea añadir una seccion con tarjetas para mostrar los tipos de cafés y postres que ofrece la cafeteria, mostrando la disponibilidad de los productos, esta seccion estara antes del formulario y luego del encabezado.
